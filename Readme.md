    Kaseb

**Kaseb** is a modern cross-platform real estate marketplace application built with **.NET MAUI**. It provides a complete solution for buying and selling properties with a clean architecture, scalable codebase, and a smooth mobile experience on both Android and iOS.

> 🚀 Built with .NET MAUI | MVVM Architecture | Cross-Platform Mobile App

---

## ✨ Features

- 📱 Cross-platform application (Android & iOS)
- 🏘️ Complete property buying and selling platform
- 📲 OTP Authentication using mobile number
- 🔐 Automatic Login & Registration flow
- ❤️ Bookmark favorite properties
- 💰 Property filtering by:
  - Price
  - Area (Square Meter)
- 💳 Support for both **Cash** and **Installment (Check)** property sales
- 👤 User account management system
- ⚡ Fast and responsive UI
- 🔄 Easily maintainable and scalable architecture

## 🏗️ Architecture

The application follows the **MVVM (Model-View-ViewModel)** design pattern, providing:

- Clean separation of concerns
- Maintainable codebase
- Easy testing
- Scalable project structure
- Better state management

---

## 🔑 Authentication

Kaseb uses **OTP (One-Time Password)** authentication based on the user's mobile number.

Features include:

- Auto Registration
- Auto Login
- Secure verification process
- No password required

---

## 🏠 Property Listings

Users can browse and publish real estate advertisements with powerful filtering capabilities.

### Filters

- Price
- Property Area

### Payment Types

- Cash
- Installment (Check)

---

## ❤️ Favorites

Users can save their preferred property listings to a personal **Bookmarks** list for quick access later.

---

## 👤 Account Management

The application includes a complete account management system where users can:

- Manage profile information
- View their advertisements
- Manage favorite properties
- Access account-related features
